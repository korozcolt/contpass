    **`app/Http/Controllers/QuotationPdfController.php`**:
    ```php
    namespace App\Http\Controllers;

    use App\Models\Quotation;
    use Barryvdh\DomPDF\Facade\Pdf;
    use Symfony\Component\HttpFoundation\Response;

    class QuotationPdfController extends Controller
    {
        public function show(Quotation $quotation): Response
        {
            $quotation->load(['lines', 'thirdParty', 'company']);

            return Pdf::view('pdf.quotation', ['quotation' => $quotation])
                ->download("{$quotation->number}.pdf");
        }
    }
    ```

    **`routes/web.php`** — añade AL FINAL del archivo, mismo patrón exacto que las rutas `accounting-reports.*` ya existentes (closure + `abort_unless`, sin usar el helper de resource routing):
    ```php
    use App\Http\Controllers\QuotationPdfController;
    use App\Models\Quotation;

    Route::get('quotations/{quotation}/pdf', function (Request $request, Quotation $quotation): mixed {
        abort_unless($request->user() !== null, 403);

        return app(QuotationPdfController::class)->show($quotation);
    })->name('quotations.pdf');
    ```

    **`QuotationsTable.php`** — añade la acción "Descargar PDF" a `->recordActions([...])`, DESPUÉS de `EditAction::make()` y antes de las acciones de ciclo de vida (color/icono gris = utilidad neutra, no transición de estado, per UI-SPEC):
    ```php
    Action::make('pdf')
        ->label('Descargar PDF')
        ->icon(Heroicon::DocumentArrowDown)
        ->url(fn (Quotation $record): string => route('quotations.pdf', $record))
        ->openUrlInNewTab(),
    ```
    (usa un enlace real, no un closure `->action()` — una descarga de archivo binario no puede volver como respuesta de una llamada AJAX de Livewire; `->url()` genera un `<a href>` que hace una petición GET completa fuera del ciclo de vida de Livewire, igual que los exports CSV existentes).

    **`ViewQuotation.php`** — añade la misma acción a `getHeaderActions()`, antes de `EditAction::make()`:

    ```php
    protected function getHeaderActions(): array

                ->icon(Heroicon::DocumentArrowDown)
                ->url(fn (): string => route('quotations.pdf', $this->record))
                ->openUrlInNewTab(),
            EditAction::make(),
        ];
    }
    ```
