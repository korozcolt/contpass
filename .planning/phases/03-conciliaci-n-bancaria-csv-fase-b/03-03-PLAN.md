```php
public function handle(BankStatementImport $import): void
{
    $windowDays = (int) config('contpass.bank_reconciliation.match_window_days', 3);
    $poolLimit = (int) config('contpass.bank_reconciliation.match_pool_limit', 10);

    $import->lines()
        ->where('status', BankStatementLineStatus::Pending)
        ->get()
        ->each(fn (BankStatementLine $line) => $this->proposeForLine($line, $import->cash_account_id, $windowDays, $poolLimit));
}
```

`proposeForLine()`:
1. `$amountCents = (int) round(abs((float) $line->amount) * 100);` `$from = $line->line_date->subDays($windowDays); $to = $line->line_date->addDays($windowDays);`
2. `$candidates = Payment::query()->where('cash_account_id', $cashAccountId)->where('is_reconciled', false)->whereBetween('paid_on', [$from, $to])->get();`
3. 1:1 — por cada `$payment` en `$candidates` cuyo `(int) round((float) $payment->amount * 100) === $amountCents`: confidence = High si `$line->reference` y `$payment->reference` no son null y coinciden (trim + `mb_strtolower`), sino Candidate. Crear `$line->matches()->create(['confidence' => $confidence, 'status' => BankStatementMatchStatus::Proposed])` y `$match->payments()->attach($payment->id)`.
4. Si `$candidates->count() > $poolLimit`, `return` (sin intentar lote — límite superior explícito, Open Question #3).
5. Si `$candidates->count() < 2`, `return`.
6. Generar combinaciones de tamaño 2 a 5 con un generador recursivo privado `combinationsOfSize(array $items, int $size): array` (sin librería — ver 03-RESEARCH.md, ~15 líneas). Por cada combinación cuya suma en centavos == `$amountCents`, crear un `BankStatementMatch` confidence=Candidate con los N Payments de esa combinación vía `$match->payments()->attach(collect($combo)->pluck('id')->all())`. Crear `app/Services/Accounting/ConfirmBankStatementMatch.php`:

```php
public function handle(BankStatementMatch $match, ?int $userId = null): void
{
    DB::transaction(function () use ($match, $userId): void {
        foreach ($match->payments as $payment) {
            $payment->update(['is_reconciled' => true]);
        }

        $match->update([
            'status' => BankStatementMatchStatus::Confirmed,
            'confirmed_at' => now(),
            'confirmed_by' => $userId,
        ]);

        $match->line->update(['status' => BankStatementLineStatus::Matched]);

        $match->line->matches()
            ->where('id', '!=', $match->id)
            ->where('status', BankStatementMatchStatus::Proposed)
            ->update(['status' => BankStatementMatchStatus::Discarded]);
    });
}
```

Nota explícita: la acción "Descartar sugerencia" (sin confirmar) NO requiere este servicio — es un `$match->update(['status' => BankStatementMatchStatus::Discarded])` trivial sin efectos sobre `Payment`, implementado directamente en la acción Filament del Plan 04 (no hay regla de negocio que proteger ahí, a diferencia de confirmar).
