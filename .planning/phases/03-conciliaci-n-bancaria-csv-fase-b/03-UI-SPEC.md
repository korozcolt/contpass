## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inline padding |
| sm | 8px | Compact element spacing (badge groups, inline meta) |
| md | 16px | Default element spacing (form field gaps, table cell padding — Filament default) |
| lg | 24px | Section padding (summary card, rejected-rows banner) |
| xl | 32px | Layout gaps between major page sections (upload form vs. review table) |
| 2xl | 48px | Major section breaks (not expected to be needed this phase) |
| 3xl | 64px | Page-level spacing (not expected to be needed this phase) |

Exceptions: none. This phase introduces two Filament artifacts — an upload form (`FileUpload` + `Select` for `CashAccount`/`BankProfile`) and a custom review page (D-09, `BankStatementReview extends Page implements HasTable`) — both inherit Filament's own internal component spacing. The scale above governs only the phase's *custom* Blade content: the summary/header card, the rejected-rows banner, and match-candidate badge groups rendered inside table columns.

## Typography

Scope: Filament v5's own theme governs all framework-rendered chrome (nav, form labels, table headers/cells, buttons) — this phase does not override the panel theme. The roles below apply specifically to the **custom Blade content** this phase introduces: the review page header, the rejected-rows banner, and status/confidence badges.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 600 (semibold) | 1.5 |
| Heading | 18px | 600 (semibold) | 1.2 |
| Display | 24px | 600 (semibold) | 1.2 |

- **Body** (14px/400): line-item descriptions, candidate match summaries, helper/instructional text (e.g. rejected-row reasons).
- **Label** (12px/600, uppercase where used as a pill): status badges (`Pendiente`, `Coincidencia`, `Rechazada`), confidence badges (`Alta confianza`, `Candidato`), table column headers (already Filament default — do not override).
- **Heading** (18px/600): section headings inside the review page — "Líneas del extracto", "Filas rechazadas", "Sugerencias de cruce".
- **Display** (24px/600, `font-display`/Space Grotesk): page title, e.g. "Revisión de extracto — {banco} · {cuenta}".

Font weights used: exactly 2 (400 regular, 600 semibold) — matches contract limit.

## Color

Filament v5 panel already configures `primary => Color::Amber` (`AdminPanelProvider.php`). This phase reuses the existing panel palette; it does not introduce new brand colors. Values below are the Tailwind-equivalent hex Filament's `Color::Amber`/default gray/`danger` resolve to, for reference only — actual rendering is framework-controlled and theme-aware (light/dark).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F9FAFB` light / `#030712` dark (Filament panel background, framework default gray) | Page canvas, panel background |
| Secondary (30%) | `#FFFFFF` light / `#111827` dark (Filament panel default surface) | Cards, table surface, sidebar, the review page's summary card and line-item rows |
| Accent (10%) | `#D97706` (Amber-600, existing `Color::Amber` primary) | Reserved for: "Importar extracto" button, "Confirmar cruce" button (per row/group), active nav item, focus rings on the `CashAccount`/`BankProfile` select fields |
| Destructive | `#DC2626` (Filament default `danger` red) | Reserved for: "Descartar sugerencia" action, rejected-row status badge, the solape/rejection error banners (D-05, D-03, BANKREC-06) |

Accent reserved for: "Importar extracto" primary CTA, "Confirmar cruce" per-row/group action, active navigation item, input focus state. Never used for confidence badges (see below) to avoid overloading the accent color with informational meaning.

**Confidence badges (D-06) — separate semantic colors, distinct from the 10% accent:**

| Confidence | Filament color token | Usage |
|------------|----------------------|-------|
| Alta confianza (monto + fecha + referencia) | `success` (green) | Badge on high-confidence proposed matches |
| Candidato (monto + fecha, sin referencia) | `gray` (neutral) | Badge on lower-confidence proposed matches — intentionally NOT `warning`/amber, to keep amber exclusive to the accent/CTA role above |

**Line status badges (BANKREC-06, D-11):**

| Status | Filament color token |
|--------|----------------------|
| Pendiente (sin candidato aún) | `gray` |
| Coincidencia propuesta | `success` or `gray` per confidence above |
| Rechazada (fila no parseable) | `danger` |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (upload) | "Importar extracto" |
| Primary CTA (confirm, per row/group) | "Confirmar cruce" |
| Secondary action (per row/group) | "Descartar sugerencia" |
| Empty state heading | "Todo conciliado" |
| Empty state body | "No quedan líneas pendientes por revisar en este extracto." |
| Error state — encabezados faltantes (D-03) | "El archivo no tiene encabezados de columna reconocibles. Verifica que sea un CSV exportado del banco seleccionado y vuelve a intentarlo." |
| Error state — período solapado (D-05) | "Este archivo se solapa con un extracto ya importado para esta cuenta (rango {starts_on}–{ends_on}). Recorta el archivo para cubrir solo fechas nuevas y vuelve a intentarlo." |
| Rejected-rows banner heading (BANKREC-06) | "Filas rechazadas" |
| Rejected-rows banner body | "{n} fila(s) no se pudieron leer y no se importaron. Revisa el motivo de cada una y corrige el archivo original antes de reintentar." |
| Destructive confirmation | Ninguna acción de esta fase requiere modal de confirmación adicional: "Confirmar cruce" ES el acto de confirmación explícita exigido por BANKREC-05 (no hay una segunda capa "¿Estás seguro?"), y es reversible mediante el `ToggleColumn` de `is_reconciled` ya existente en `PaymentsTable`. "Descartar sugerencia" no modifica ningún `Payment` (solo cambia `BankStatementMatch.status` a `discarded`), por lo que tampoco requiere modal. |
