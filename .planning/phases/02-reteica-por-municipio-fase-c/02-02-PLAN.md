<objective>
Extender `WithholdingRule` (migración + modelo) para que una regla quede ligada a un municipio y a un `WithholdingType` en vez del campo `concept` de texto libre (D-04), y bloquear en el service layer la creación de dos reglas ICA activas del mismo municipio con vigencia solapada (D-08).

Purpose: RETICA-02 exige reglas ICA parametrizables por municipio reusando el versionado ya existente de `WithholdingRule` (`scopeEffectiveOn`); RETICA-04 exige que nunca se acumulen retenciones de más de un municipio — la mitad de esa garantía se impone aquí, al impedir configurar el conflicto en origen (la otra mitad, el filtro en tiempo de causación, es Plan 03).
Output: `withholding_rules` con columnas `type`/`description`/`municipality_id` (sin `concept`), `EnsureNoOverlappingIcaRule` wired en las páginas Create/Edit del recurso Filament, formulario/tabla actualizados.

Create `app/Services/Accounting/EnsureNoOverlappingIcaRule.php`:
```php
namespace App\Services\Accounting;

use App\Enums\WithholdingType;
use App\Models\Company;
use App\Models\WithholdingRule;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Validation\ValidationException;

class EnsureNoOverlappingIcaRule
{
    public function handle(Company $company, int $municipalityId, string $startsOn, ?string $endsOn, ?int $ignoreId = null): void
    {
        $overlaps = WithholdingRule::query()
            ->whereBelongsTo($company)
            ->where('type', WithholdingType::Ica)
            ->where('municipality_id', $municipalityId)
            ->where('is_active', true)
            ->when($ignoreId, fn (Builder $query) => $query->whereKeyNot($ignoreId))
            ->where('starts_on', '<=', $endsOn ?? '9999-12-31')
            ->where(fn (Builder $query) => $query->whereNull('ends_on')->orWhere('ends_on', '>=', $startsOn))
            ->exists();

        if ($overlaps) {
            throw ValidationException::withMessages([
                'starts_on' => 'Ya existe una regla ICA activa para este municipio con vigencia solapada.',
            ]);
        }
    }
}
```
